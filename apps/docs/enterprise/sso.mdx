# Single Sign-On (SSO)

EduAI supports Google OAuth 2.0 and Microsoft (Azure AD) OIDC for SSO.

## Google OAuth

Redirect users to:
```
GET /auth/google?tenantId=YOUR_TENANT_ID
```

After authentication, users are redirected to your configured callback URL with a JWT.

## Microsoft / Azure AD

Redirect users to:
```
GET /auth/microsoft?tenantId=YOUR_TENANT_ID
```

## Configuration (Super Admin)

Set in your environment:
```env
GOOGLE_CLIENT_ID=your-google-client-id
GOOGLE_CLIENT_SECRET=your-google-client-secret
GOOGLE_CALLBACK_URL=https://api.eduai.example.com/auth/google/callback

MICROSOFT_CLIENT_ID=your-azure-client-id
MICROSOFT_CLIENT_SECRET=your-azure-client-secret
MICROSOFT_TENANT_ID=your-azure-tenant-id
MICROSOFT_CALLBACK_URL=https://api.eduai.example.com/auth/microsoft/callback
```
